SayGuard · Stage I proposal · 5 · measured: Qwen2.5-1.5B-Instruct via Ollama on the PC GPU · UGen300 build (hailo-ollama) not yet measured

We give the local language model two jobs, and it never sets a number, a camera or a live rule on its own. For rules it drafts the structure, a deterministic checker overwrites the numbers, times and objects it finds in the sentence, like the ten pm example at the bottom, and the officer confirms before the rule goes live; the checker's own rule extractor handles familiar phrasings without the model, and the model adds the rephrasings the extractor misses. For the daily report nobody confirms the plan, so code computes every number and the model may only choose which listed issues matter and which vetted fix applies; it cannot invent a camera or a figure. Both jobs work in Mandarin or English the way people on site speak, and if the model is offline the rule extractor alone still parses most typed test sentences.
