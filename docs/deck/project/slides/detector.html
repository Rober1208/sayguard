Each class a site depends on gets a trained detector. The hard-hat model scores 0.939 mAP50 on test images it never saw, and it is already compiled for Hailo-10H, where INT8 barely changes its accuracy in Hailo's emulator. The warehouse model knows six classes of people, vehicles and robots. For anything else a spoken rule names, like the excavator here, YOLO-World works from the word alone; this is a demo and its accuracy is not measured yet, and in our warehouse tests it was no substitute for the trained forklift detector, which is why everyday classes get a trained model.
