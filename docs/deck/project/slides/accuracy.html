Every sentence here was typed, and held out when it was measured: none had been used to build the checker. In hard-hat mode the small model alone gets 40 percent exactly right; it can, for example, guess a time window or misname an object. With the checker it reaches 95, and the rule extractor alone, which is the checker's own parser run without the model, already gets 90, so the model's share is the rephrasings the extractor misses. The warehouse sentences were written and labelled by AI agents that never saw our parser code. We report the first set's first run; we then fixed what it exposed, so that set is no longer clean, and measured a fresh set from a new pair, so neither figure comes from sentences we tuned on.
