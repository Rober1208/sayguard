SayGuard · Stage I proposal · 7 · screenshot: SayGuard prototype · docs/results/rule_parsing*.json

The officer holds the button and says the rule. Whisper turns it into text, primed with the site's own zone and object names. The small language model does not write an answer; it fills a fixed rule form, and because the form is typed, code can check it: every number, time and object stated in the sentence is corrected if the model got it wrong. The officer then reads the rule in plain words and switches it on. On sentences the parser never saw during development, this gets 95 percent of construction-site rules and 84 to 88 percent of warehouse rules exactly right, against 40 and 16 to 24 percent for the language model alone. Nothing needs to be collected or retrained for a new rule about objects, zones, distances, counts or times the system already knows.
