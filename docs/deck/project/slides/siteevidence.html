We tested warehouse mode on six synthetic warehouses the detector never trained on, with every setting chosen on a separate validation scene. Fusing all cameras on one floor plan keeps the head count within about two people of the truth, where simply summing the cameras can be off by sixty. Every entry through a door or dock zone was alerted with no false alerts, and the forklift rule caught ninety-two percent of close calls. An event counts as alerted when the worker got an alert or was still inside the cooldown of one; the strict numbers and a run with the settings frozen before any fix are in the results folder of the repository.
