WAREHOUSE MODE

Every camera on one floor plan

Each worker counted once, not once per camera

Zones drawn on the plan

This is warehouse mode, running on a synthetic eleven-camera warehouse we use as our demo scene. Instead of judging each camera on its own, SayGuard places every detection on one floor plan, so a worker seen by several cameras is one dot and one count, not one per camera, and each entry into a zone raises one alert, not one per camera. Summing cameras counts many workers twice or more; the floor plan stays close to the truth. Zones are drawn once on the plan, forklift distances are measured in metres, and the officer can speak a rule using the zone names the site already uses.
