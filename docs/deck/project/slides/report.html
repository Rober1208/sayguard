The second job we give the small LLM is planning the daily report. Code does all the counting, so every number and table comes straight from the alert log. The model only chooses which issues matter today and picks one vetted fix for each, answering with numbers under a JSON schema; nobody approves this plan by hand, which is why the model may only choose from listed issues and vetted fixes. Two blind AI judges rated every action from three designs: when the model wrote actions freely, it sometimes aimed at the wrong problem; when it picked from the vetted list, it never did in our test, and there the judges rated only the choice, because the wording is our own.
