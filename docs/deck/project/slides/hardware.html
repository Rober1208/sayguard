Integration is deliberately simple. SayGuard reads the RTSP streams a site already records, so no camera or recorder is replaced. A mini PC decodes the video, tracks workers, places them on the floor plan, applies the rules and serves the dashboard, and a UGen300 on USB runs every neural network. In today's prototype the same software runs on a PC GPU; ten hard-hat cameras run through one batched detector, all one hundred frames per second, which we estimate at about forty percent of one UGen300. A site adds one box per area of up to twelve cameras.
