ANYTHING ELSE A RULE NAMES

“Warn me if anyone is near the excavator”

YOLO-World finds objects from the word itself, so a rule can name things no detector was trained on. Classes a site depends on every day still get a trained detector.

SayGuard · Stage I proposal · 11 · docs/results/: detector_metrics, hailo_int8, site_same_nms, site_hef · Roboflow Hard Hats v2 (CC BY 4.0)

Each class a site depends on gets a trained detector. The hard-hat model scores 0.939 mAP50 on test images it never saw, and it is already compiled for Hailo-10H. In Hailo's INT8 emulator we re-score it with the NMS built into the HEF, a separate evaluation from the 0.939; there INT8 scores 0.889 against 0.893 for float, so quantization costs almost nothing. The warehouse model knows six classes of people, vehicles and robots, and it is compiled for the chip too, with INT8 matching float in Hailo's emulator. Neither has run on hardware yet. For anything else a spoken rule names, like the excavator here, YOLO-World works from the word alone; this is a demo and its accuracy is not measured yet, and in our warehouse tests it was no substitute for the trained forklift detector, which is why everyday classes get a trained model.
