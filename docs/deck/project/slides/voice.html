SayGuard · Stage I proposal · 6 · screenshot: SayGuard prototype, Say a rule panel

The officer holds the button and says the rule. Whisper-Small transcribes it, primed with the site's own zone and object names to help it transcribe them correctly. The small LLM drafts the rule as structured JSON, and a deterministic checker then overrides the numbers, times and objects it finds stated in the sentence; it can miss an unusual phrasing, which is why the officer reads the result in plain words before switching it on. If the LLM is offline, the checker's own rule extractor still parses most typed test sentences; speech recognition accuracy itself has not been measured yet.
