SayGuard is designed to put one ASUS UGen300 next to the video recorder of each site area and watch every camera in it; today the Stage I prototype runs the same software on a local PC GPU. Safety officers set the rules by saying them, in Mandarin or English. Like TypeSafe AI's Jev, every decision SayGuard asks an AI model for comes back as a typed answer rather than text, which keeps the models small enough for a 2.5-watt chip and easy for code to check.
