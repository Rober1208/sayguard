This is the idea that runs through all of SayGuard. TypeSafe AI's Jev showed that much of what software asks an AI is not a conversation but a decision: a yes or no, a choice from a fixed list, a typed form. Jev itself is a cloud service, and a safety box has to decide on site, so we rebuilt the same idea from small models that Hailo already supports on the Hailo-10H. Jev cannot run on premises, so for the alert check we replaced our generative vision-language model, Qwen2-VL-2B, with a Jev-style model of our own: an image encoder and a two-way decision head. It is about eighteen times faster and more accurate on the same held-out crops. The language model fills a fixed rule form that code can check, and for the daily report it only chooses among real issues and vetted fixes. Because every answer is typed, code can verify it, and that is why a 1.5-billion-parameter model is enough.
