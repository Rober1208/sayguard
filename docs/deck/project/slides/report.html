The second job of the small language model is the daily safety report, and again it makes a choice rather than writing prose. Code computes every number and table from the alert log. The model sees only the problems that really happened today, with a short list of vetted fixes for each kind, and answers with numbers: which problems matter most and which fix goes with each. We compared this with letting the model write the actions freely: across twenty synthetic days, judged blind by two AI judges, free text aimed one action in five at the wrong problem, and the choice-based plan never did. That is why the report can go out without anyone rewriting it.
