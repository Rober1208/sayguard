We train a detector for every class a site depends on. The hard-hat model is scored on test images it never saw, and it is already compiled for Hailo-10H, though not yet run on hardware; in Hailo’s emulator INT8 barely changes its accuracy compared with the float model in the same Hailo toolchain, which is a different evaluation from our PC score. The warehouse model learned from eight synthetic scenes in five buildings; it found almost every forklift on Warehouse_010, our demo scene, but far fewer in two other test buildings, and we have not yet established why. For anything else a spoken rule names, YOLO-World works from the word alone, as the excavator demo shows, though we have not measured its accuracy; it missed every forklift in that same warehouse, which is why site-critical classes get a trained model.
